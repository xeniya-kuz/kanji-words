# kanji.db

Generated by `npm run build:kanji-db` (see `scripts/build-kanji-db.mts`). Do not edit by hand.

| Table | Contents |
|---|---|
| `kanji` | ~3,400 kanji (Jōyō, Jinmeiyō, RTK, frequent): strokes, grade, JLPT, frequency, RTK frame, readings, English meanings, components |
| `similar` | up to 15 look-alike kanji per kanji, scored 0..1 |
| `kanji_reading` | reading (hiragana) → kanji, for same-reading substitutes |
| `word` | JMdict spellings by reading with their entry id and a "common" flag: spellings of the same entry are alternatives, other entries with the same reading are homophones |

`PRAGMA user_version` holds the data version (`DB_VERSION` in the script).
